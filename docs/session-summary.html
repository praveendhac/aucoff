3. Key decisions

  • Scope: v1 local-only on kind (no AWS; minikube not used); AWS/Terraform/EKS are post-v1 (ADR-13, ENV-4, NFR-12). Multi-tenant SaaS, operator-provisioned tenants, audited break-glass operator access, time-boxed scoped external auditors.
  • Frameworks (all in v1): PCI DSS v4.0.1, PCI 3DS, SOC 2, ISO 27001:2022, ISO 27701:2025, ISO 20022-1:2026 (Ed. 3), GDPR, DPDP, RBI DPSC and PPI, FFIEC BSA/AML 2026 and IT Handbook, FTC Safeguards, GLBA, NYDFS 500, PSD2, DORA. Versions are owner-supplied and must be verified.
  • Stack: Next.js + shadcn/ui + Tailwind + TanStack Query; Python 3.13 FastAPI gateway + agent services over RabbitMQ; LangGraph; PostgreSQL 18.6 + pgvector 0.8.6 (owner-confirmed) with row-level security; Auth.js + Keycloak; OpenAPI at backend/openapi.yaml with Swagger for all endpoints.
  • AI controls: deterministic checks first (wrapped open-source scanners), advisory-only agents, human approval for consequential actions and anything leaving the tenant, citation validation, redaction before LLM calls, eval gates (citation 98%, hallucination 1%, agreement 90%, redaction 99%), budgets USD 25/10.
  • History: 12 months visible (stored 13), immutable snapshots, any-to-any scan comparison.
  • Licensing rule (LIC-1 to LIC-8): permissive licences only; anything with a licence or provenance issue is replaced. Unapproved pending verification (from my unverified recollection): MinIO, Grafana/Loki/Tempo, Steampipe, ScoutSuite, Semgrep rules; audit task T-009.

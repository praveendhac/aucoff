# Local reference documents (never committed)

Copy the licensed framework documents here, one file or folder per framework, for example:

```
reference/soc2-2017/            reference/pci-dss-4.0.1/
reference/rbi-dpsc-2026/        reference/iso27001-2022/
```

Everything in this folder except this README is ignored by git (`reference/.gitignore`), so the
texts stay on this laptop. They are used only to read clause identifiers and meaning; the control
catalogue stores our own wording and clause identifiers, never the standard's text (LIC-6).
Prefer text, Markdown, DOCX, XLSX or CSV; large PDFs can be read but slowly (20 pages per read).
